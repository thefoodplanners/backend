### Installation

- Install JDK
- Install Scala
- Install SBT

- To compile source files, `sbt compile`
- To compile source and test files, `sbt Test/compile`
- To run tests, `sbt test`

### Running the project

- Clone the repository
- Install `docker` and `docker-compose`
- Call `docker-compose up -d`
- To close the server, call `docker-compose down`
- (This runs both the project and the PostgreSQL server)
